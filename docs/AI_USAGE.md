# AI 사용 로그

2026 오픈소스 개발자대회 운영규정 제9조⑤ 대응 문서. AI를 어디에 썼고, **사람이 무엇을
판단·검증했는지**를 기록한다. "AI가 작성한 코드의 동작 원리에 대한 이해도가 부족할 경우
평가 시 감점될 수 있다"는 규정에 따라, 핵심 알고리즘(큐 수지 방정식·물리 제약 최적화)은
AI에 위임하지 않고 팀원이 직접 설계·구현한다.

각 팀원은 아래 표에 본인이 AI를 사용한 지점을 추가한다.

## 원칙

- 핵심 알고리즘(큐 수지 역추정, 물리 제약 최적화, 환승률 추정)은 AI가 초안을 작성하더라도
  **팀원이 수식과 동작 원리를 직접 검증**하고, 발표 질의응답에서 설명할 수 있어야 한다.
- 반복적/정형적 작업(보일러플레이트, 문서 초안, 테스트 스캐폴드)에는 AI를 적극 활용한다.
