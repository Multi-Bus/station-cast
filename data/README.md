# 데이터 출처

> **담당: A 트랙.** 이 문서는 S1~S4에 채워집니다. 운영규정 제8조⑤⑥(출처·라이선스 명시 의무)
> 대응 문서입니다.

각 데이터셋마다 아래 항목을 기재합니다.

- 출처 (기관, URL)
- 이용 조건 (출처 표시 의무 등)
- 수집 일자 / 수집 방법
- 필드 설명
