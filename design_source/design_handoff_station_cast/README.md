# Handoff: Station Cast — 실시간 정류장 혼잡도 앱

## Overview
Station Cast는 버스 정류장의 **대기 혼잡도**를 실시간으로 추정해 보여주는 모바일 앱입니다.
지도가 항상 바탕에 깔리고, 정보는 아래에서 드래그로 올려 여는 바텀시트에 담깁니다 (네이버지도 방식).
승·하차 실측 데이터에 큐 수지 모델을 적용해 "대기 인원"을 추정하며, 모든 혼잡도 수치는 **추정치**임을 UI에서 명시합니다.

이 번들에는 **라이트 모드**와 **다크 모드** 두 벌의 전체 화면 세트가 들어 있습니다.

## About the Design Files
이 번들의 `.dc.html` 파일은 **HTML로 만든 디자인 레퍼런스**입니다. 의도한 외형과 동작을 보여주는 프로토타입이며,
그대로 가져다 쓸 프로덕션 코드가 아닙니다.

과제는 이 HTML 디자인을 **대상 코드베이스의 기존 환경에서 재현하는 것**입니다 (React Native / Flutter / SwiftUI /
Kotlin Compose 등). 기존 환경이 있다면 그 프로젝트의 컴포넌트·상태관리·네비게이션 패턴을 따르고,
아직 환경이 없다면 프로젝트에 가장 적합한 프레임워크를 골라 구현하세요.
지도는 실제 지도 SDK(네이버 지도 / Google Maps / MapKit)로 대체합니다 — 프로토타입의 지도는 CSS 격자와
사각형으로 그린 **플레이스홀더**입니다.

## Fidelity
**High-fidelity (hifi).** 색상, 타이포그래피, 간격, 반경, 상태 색이 모두 확정된 값입니다. 픽셀 단위로 재현하되,
플랫폼 관용구(터치 타깃 44pt, 안전영역, 네이티브 시트 제스처)는 플랫폼 표준을 우선하세요.

## Screens / Views

프레임 기준: iPhone 390 × 844. 하단 탭바 56px 고정. 상태바는 프레임 컴포넌트가 그립니다.

### ⓪ 온보딩
- **Purpose**: 앱의 가치 제안 전달 후 진입.
- **Layout**: 전체 화면 단색 배경, 좌측 정렬, 세로 flex. padding `28px 24px 32px`. 상단 여백 flex:1로 콘텐츠를 수직 중앙에.
- **Components**:
  - 로고 마크: 64×64, radius 10px, 흰 배경, 텍스트 "SC" 800 26px, 색은 배경색과 대비되는 진회색.
  - 헤드라인: 30px / line-height 1.15, "정류장 혼잡도,\n도착 전에 확인하세요"
  - 본문: 14px / 1.6, 85% 불투명도, "실시간 승하차 데이터를 분석해 정류장별 대기 혼잡도를 알려드립니다."
  - 버튼 2개 (세로 스택, gap 10px, 각 높이 약 46px, radius 10px, 라벨 중앙 정렬):
    - Primary: 흰 배경 / 진회색 글자 — "시작하기"
    - Secondary: 투명 배경 / 흰 글자 / `1px solid rgba(255,255,255,.4)` — "둘러보기"
- 라이트 모드 온보딩 배경은 밝은 톤, 다크 모드는 `#444141`.

### ① 지도 기본 · 위치기반 (시트 Peek)
- **Purpose**: 앱 진입 기본 화면. 내 위치 주변 정류장을 지도에서 확인.
- **Layout**: 지도 전면 → 상단 플로팅 검색바 + 필터칩 → 우하단 지도 컨트롤 → 시트 Peek(약 높이 120px) → 탭바.
- **Components**:
  - **플로팅 검색바**: 상단 safe-area 아래 12px, 좌우 16px, 높이 46px, radius 9999px, 흰 배경 + `0 2px 8px rgba(0,0,0,.16)`.
    좌측 검색 아이콘(15px, neutral-500), 플레이스홀더 "정류장, 노선, 주소 검색" 14px neutral-500, 우측 32px 원형 프로필(SC).
  - **필터칩 행**: 검색바 아래 gap 7px, 가로 스크롤. `.chip` = 흰 배경 pill, padding 7px 14px, 600 12px.
    선택 칩(`.chip-on`)은 진회색 배경 + 흰 글자 700.
  - **지도 마커**: 물방울 핀 26×26 (`border-radius:50% 50% 50% 0` + `rotate(-45deg)`), 혼잡도 색 채움, 2px 흰 테두리.
    핀 위 라벨 pill: 흰 배경, 800 10px, 혼잡도 색 글자, 예: "강남역 · 혼잡".
  - **내 위치 점**: 11px 원, 2px 흰 테두리, 파란색 대신 진회색.
  - **지도 컨트롤**: 38×38, radius 9px, 흰 배경 + 그림자. 위→아래: 레이어(☰), 현재위치(◎, 진회색 반전).
  - **시트 Peek**: 하단 탭바 위에 붙음. radius `14px 14px 0 0`, 상단 그랩바 38×4 radius 2px neutral-300.
    Peek 콘텐츠: "내 주변 정류장 4곳" + 가장 가까운 정류장 1행 요약.
  - **탭바**: 4탭 — 지도 / 즐겨찾기 / 회랑 / 설정. 아이콘 위, 라벨 600 10px, 활성 탭은 800 + text 색, 비활성 neutral-500.

### ② 주변 정류장 목록 (시트 Half)
- **Purpose**: 주변 정류장을 거리·혼잡도 순으로 비교.
- **Layout**: 시트 `top:46%`. 지도는 위쪽 46%에 계속 보임.
- **Components**: 정류장 행 리스트. 각 행 —
  - 좌: 정류장명 15px 700, 아래 노선번호 + 거리 12px neutral-600
  - 우: 혼잡도 배지(pill, radius 9999px, padding 3px 9px, 700 11px, 혼잡도 색 배경), 아래 "대기 N명" 11px
  - 우측 끝: 즐겨찾기 별 (★ 채움 = `#e8bb2a`, ☆ 비움 = neutral-400)
  - 행 사이 `1px solid var(--color-divider)`

### ③ 정류장 상세 (시트 Full)
- **Purpose**: 한 정류장의 현재/시간대별 혼잡도, 도착 정보, 날씨 컨텍스트 확인.
- **Layout**: 시트가 화면 전체(탭바 위)까지 확장. 내부 스크롤. 섹션 gap 14px, padding 좌우 16px.
- **Components** (위→아래):
  1. **헤더**: 정류장명 20px 800 + 노선 목록 + 즐겨찾기 토글 버튼
  2. **현재 혼잡도 히어로**: 혼잡도 색 배경 블록, radius 10px. "혼잡" 라벨 + "추정" 배지 + 본문 "대기 약 42명 · 신뢰구간 34–51명" 12px 흰색 85%
  3. **날씨 컨텍스트 카드**: `.card .elev-sm`, radius 10px, `1px solid` 카드라인. ☂ 아이콘 + "비 · 12°C" + 보조문 "강수 시 대기 인원이 평균 18% 증가합니다"
  4. **버스 도착 정보 카드**: radius 10px, padding 0, 행 리스트. 각 행 — 노선번호 700 14px / "N 정류장 전" 11px neutral-600 / 우측 ETA 700 15px + 차내 혼잡 배지
  5. **시간대별 예상 혼잡도**: 막대 그래프. 07~22시 16개 막대, 값에 따라 색 자동(≥70 → `#dd3a3a`, ≥40 → `#e8bb2a`, 그 외 `#35c96a`). 막대 아래 시간 라벨 9px.
  6. **통계 3열**: 카드 3개 flex:1 gap 10px, radius 10px + 카드라인 border. "오늘 평균 63%" / "최고 혼잡 18시" / "전일 대비 +9%"
  7. **면책 문구**: 11px / 1.45 neutral-500 — "대기인원은 승·하차 실측 데이터에 큐 수지 모델을 적용한 추정치입니다."

### ④ 검색 — 빈 상태
- **Purpose**: 검색 진입. **지도가 깔리지 않는 독립 페이지**입니다.
- **Layout**: 배경 `--color-bg`, padding-top 56px. 상단 검색바 행 → 퀵액션 행 → 인기 검색어 → 최근 검색.
- **Components**:
  - 검색바: 뒤로가기 ← + 입력 필드(높이 46px, radius 9999px, surface 배경, `1px solid` neutral 테두리)
  - 퀵액션 행: "◎ 내 주변" (원형 22px 진회색 채움 아이콘) / "▣ 지도에서" (22px radius 6px surface + 테두리) / 우측 "★ 즐겨찾기"
  - **인기 검색어** (최근 검색보다 위): 순위 숫자 + 키워드 리스트
  - **최근 검색**: 아이콘(◎ 장소 / ⌕ 검색어) + 이름 + 날짜(07.25. 형식) + 삭제 ✕
- 입력이 비어 있을 때만 이 화면. 한 글자라도 입력되면 ⑤로 전환.

### ⑤ 검색 — 입력 중 (검색 결과)
- **Layout**: ④와 동일한 골격(같은 검색바, 같은 패딩) — 빈 상태가 기준입니다. 리스트만 결과로 교체.
- **Components**: 입력 필드에 쿼리 텍스트("강남") + 우측 18px 원형 ✕ 클리어 버튼.
  결과 행 — 정류장/노선 아이콘 + 이름(쿼리 부분 강조) + 주소·노선 보조문 + 혼잡도 배지.

### ⑥ 검색 결과 상세 (시트 Half)
- **Purpose**: 검색 결과에서 정류장 선택 직후 상태.
- **Layout**: 지도 복귀 + 선택 마커 확대(34×34) + 검색바에 쿼리 유지. 시트는 `top:52%` (**Half**).
- **중요**: 이 시트를 위로 드래그하면 **③ 정류장 상세와 완전히 동일한 콘텐츠**가 나와야 합니다 (같은 컴포넌트 재사용).

### ⑦ 즐겨찾기
- **Purpose**: 저장한 정류장 모니터링.
- **Layout**: ①과 같은 지도 바탕 + 드래그 시트 구조. 탭바에서 "즐겨찾기" 활성.
- **Components**: 즐겨찾기 카드 리스트 — 정류장명 / 노선 / 혼잡도 배지 / "대기 N명" / "다음 버스 N분 후"

### ⑧ 회랑 (Corridor)
- **Purpose**: 한 노선 축의 여러 정류장 혼잡도를 한눈에 비교.
- **Components**: 정류장별 수평 바 — 이름(왼쪽 고정폭) + 퍼센트 바(혼잡도 색) + 수치. 7개 정류장.

### ⑨ 운영자 대시보드 (데스크톱)
- **Purpose**: 운영자가 전체 정류장 혼잡 현황을 감시.
- **Layout**: 브라우저 창 프레임. 좌측 사이드바 + 상단 헤더 + KPI 카드 행 + 데이터 테이블.
- **Components**: KPI 카드 4개, `.table` 클래스 데이터 테이블 — 컬럼: 정류장 / 노선 / 평균 혼잡 / 상태 / 전일 대비 / 대기 인원.

### ⑩ 상세 통계 (데스크톱)
- **Components**: 시간대별 혼잡도 그래프(확대판) + 통계 카드 + 정류장 순위 테이블.

## Interactions & Behavior
- **바텀시트 3단 스냅**: Peek(약 120px) → Half(화면 46~52%) → Full(탭바 위 전체). 드래그로 전환, 스냅 애니메이션 약 280ms `cubic-bezier(.2,.8,.2,1)`. 시트를 아래로 끌어 Peek까지 닫을 수 있음.
- **지도는 항상 바탕**: 시트가 Half/Full일 때도 지도가 뒤에 남아 있어야 합니다. 유일한 예외는 검색 페이지(④⑤) — 독립 전체 화면.
- **검색 상태 분기**: 입력 비어 있음 → 인기 검색어 + 최근 검색 / 입력 있음 → 결과만.
- **검색 결과 선택 → ⑥**: 지도로 돌아오며 시트가 **Half에서 시작**합니다 (Full 아님).
- **즐겨찾기 토글**: 별 아이콘 탭 → 채움/비움 전환. 로컬 저장(localStorage / AsyncStorage / UserDefaults).
- **마커 탭** → 해당 정류장 시트 Half.
- **현재위치 버튼** → 지도 카메라를 내 위치로, 주변 정류장 재조회.
- **탭바** → 지도 / 즐겨찾기 / 회랑 / 설정 전환. 탭 전환 시 시트 상태는 Peek로 초기화.
- **로딩**: 정류장 카드·리스트는 스켈레톤(neutral-200 블록) 사용. **에러**: "혼잡도를 불러올 수 없습니다 · 다시 시도" 인라인 표시.
- 혼잡도 수치가 표시되는 모든 곳에는 "추정" 배지 또는 신뢰구간이 함께 나와야 합니다.

### Spacing
4px 배수. 화면 좌우 패딩 16px(온보딩 24px), 섹션 간 14px, 카드 내부 12~14px, 리스트 행 세로 10~12px, 칩 gap 7px, 카드 gap 10px.

### Shadow
| 이름 | 값 |
|---|---|
| 플로팅(검색바·컨트롤·칩) | `0 2px 8px rgba(0,0,0,.16)` / 칩 `0 1px 5px rgba(0,0,0,.14)` |
| 시트 | `0 -6px 20px rgba(0,0,0,.14)` |
| 지도 마커 | `0 2px 6px rgba(0,0,0,.3)` |
| 카드 | 디자인 시스템 `.elev-sm` |

### 터치 타깃
최소 44×44. 지도 컨트롤은 시각적으로 38px이나 히트 영역은 44px로 확장하세요.

## 구현 순서 제안
1. 테마 토큰(라이트/다크) + Pretendard + 혼잡도 색 시스템

6. 즐겨찾기(⑦) + 회랑(⑧)
7. 운영자 대시보드(⑨⑩) — 별도 웹 앱으로 분리 가능
